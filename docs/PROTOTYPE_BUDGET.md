# MULTINEURA – Estimated Prototype Development Budget

## 1. Budget Overview

The estimated budget for developing the initial MULTINEURA EEG-based Brain–Computer Interface prototype is ₹10,000.

The proposed budget covers neural signal acquisition, signal conditioning, embedded processing, power supply, hardware interfacing and application demonstration.

## 3. Budget Notes

- ESP32 is proposed as the primary embedded controller.
- A separate microcontroller and HC-05 Bluetooth module are excluded from this revised configuration.
- Application-specific components are included to demonstrate the platform's integration capabilities.
- The final EEG acquisition hardware must be verified for suitability, safety and signal quality.
- Costs are indicative and may vary according to supplier, specifications and availability.

## 4. Project Scope

MULTINEURA is envisioned as a multipurpose EEG headband platform. The listed application hardware represents demonstration examples and does not restrict the platform to these applications.

The headband architecture is intended to support integration with different external systems through suitable hardware and software interfaces.
